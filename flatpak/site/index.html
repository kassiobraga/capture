Instalação

Pronto em menos de um minuto

Distribuído em Flatpak direto pelo GitHub Pages, com atualizações automáticas sempre que sair uma versão nova.

Instalar com 1 clique

Baixe o instalador Flatpak e abra pela loja de aplicativos do seu Linux (Linux Mint, Fedora, Pop!_OS ou GNOME Software).

Baixar Capture 1.5.0 (.flatpakref)

No Ubuntu, instale o suporte antes: sudo apt install flatpak

Associar à tecla Print

Crie um atalho personalizado nas configurações de teclado apontando para:

flatpak run io.github.kassiobraga.Capture --novo

Evolução pública

Roadmap do Capture

Desenvolvimento aberto e contínuo. Veja o que acabou de chegar na 1.5 e os próximos passos planejados.

v1.5.0 Disponível

Gravação MP4 com voz e Sobre

Captura de microfone (PulseAudio/PipeWire) no MP4 com indicador ao vivo, fallback seguro para vídeo puro, opções CLI (--com-audio / --sem-audio) e janela Sobre.

v1.6 Próxima

Produtividade no editor

Zoom e rolagem para imagens compridas, marcadores numerados (1, 2, 3), colar imagem (Ctrl+V), abrir JPEG/WebP e dimensões ao vivo na seleção.

v2.0 Planejado

Suporte nativo a Wayland

Integração completa com portais xdg-desktop-portal e PipeWire para funcionar com a mesma agilidade em sessões Wayland puras.
