Capture

Captura de tela e anotação para Linux. Aperte Print, selecione e a imagem já fica copiada e salva.

Instalar o Capture

Funciona no Linux Mint, Ubuntu, Fedora e outros com Flatpak, em sessão X11.

Como instalar

  1. Clique em Instalar o Capture. O arquivo abre no Gerenciador de Aplicativos.
  2. Confirme a instalação. Na primeira vez ele também baixa a base do GNOME, que é maior.
  3. Saia da sessão e entre de novo para o Capture aparecer no menu.

As atualizações chegam sozinhas pelo Gerenciador de Atualizações.

Pelo terminal

flatpak install --user https://kassiobraga.github.io/capture/io.github.kassiobraga.Capture.flatpakref

No Ubuntu, instale o Flatpak antes: sudo apt install flatpak.

Tecla Print

Crie um atalho de teclado personalizado com o comando abaixo e associe à tecla Print (no Cinnamon: Configurações do sistema → Teclado → Atalhos → Atalhos personalizados):

flatpak run io.github.kassiobraga.Capture --novo

Código e notas de versão: github.com/kassiobraga/capture · baixar o arquivo .flatpak
